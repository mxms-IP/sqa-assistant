# BUG-001.md

**ID:** BUG-001  
**Title:** Chatbot icon appears on search results page, not only on product screen  
**Severity:** Medium  
**Priority:** Medium  
**Status:** Fixed  
**Reported by:** Arjun Nair  
**Build (reported):** v0.9.0  
**Build (fixed):** v0.9.1  
**Environment:** Chrome 124, desktop, Windows 11

---

**Steps to reproduce:**
1. Log in to Amazon staging.
2. Search for "Samsung Galaxy S22".
3. Observe the search results page before clicking any product.

**Expected result:**  
Per Technical Requirement 1, the chatbot icon should appear only after a user selects a particular product and is on the product screen.

**Actual result:**  
The chatbot icon was visible on the search results page. Clicking it opened the chatbot with no product context loaded, returning a "no product selected" error.

**Related PRD requirement:** Technical Requirement 1  
**Related test case:** TC-001

**Notes:** Fix confirmed in build v0.9.1. Icon now correctly gated behind product page navigation. Regression test passed.
