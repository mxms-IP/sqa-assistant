# BUG-010.md

**ID:** BUG-010  
**Title:** Chatbot response time exceeds 3-second limit for Tamil language queries  
**Severity:** Medium  
**Priority:** Medium  
**Status:** Cannot Reproduce  
**Reported by:** Kiran Desai  
**Build:** v0.9.2  
**Environment:** Chrome 124, desktop, Windows 10

---

**Steps to reproduce:**
1. Open chatbot on the Samsung Galaxy S22 product page.
2. Select Tamil as the preferred language.
3. Submit a query in Tamil asking about product specifications.
4. Measure response time from query submission to response display.

**Expected result:**  
Per the test plan performance requirement, the chatbot must respond within 3 seconds for all languages including Tamil.

**Actual result (reported):**  
Reporter observed response times of 5–7 seconds for Tamil queries during exploratory testing session on 2026-09-09.

**Related PRD requirement:** Technical Requirement 5; PRD Key Metrics (Response Time)  
**Related test case:** TC-011

**Notes:** QA lead Riya Menon attempted to reproduce on 2026-09-11 across three devices (Chrome desktop, Firefox desktop, Safari mobile) — all Tamil query responses came back within 2.1–2.8 seconds. Cannot reproduce with current build and network conditions. Possible cause: reporter may have been on a throttled VPN during original observation. Kiran Desai to re-test from office network. Leaving open pending re-test.
