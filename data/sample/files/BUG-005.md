# BUG-005.md

**ID:** BUG-005  
**Title:** Bank offers query returns empty response with no error message  
**Severity:** High  
**Priority:** High  
**Status:** Open  
**Reported by:** Priya Sharma  
**Build:** v0.9.2  
**Environment:** Firefox 125, desktop, Windows 10

---

**Steps to reproduce:**
1. Open chatbot on the Samsung Galaxy S22 product page.
2. Type: "Are there any bank offers available?"

**Expected result:**  
Per Technical Requirement 3, the chatbot should return available bank offers (cashback, EMI, etc.) for the currently viewed product.

**Actual result:**  
The chatbot displays a blank response bubble — no text, no error, no fallback message. The input field becomes responsive again after approximately 4 seconds but nothing is shown to the user.

**Related PRD requirement:** Technical Requirement 3  
**Related test case:** TC-007

**Notes:** Bank offers data exists in the mock product database for Galaxy S22 (confirmed by direct DB query). Issue appears to be in the response rendering layer, not the data retrieval. Reproduces consistently. Engineering investigating null-render bug in the chat UI component.
