# BUG-011.md

**ID:** BUG-011  
**Title:** Hindi language selection shows English response text  
**Severity:** High  
**Priority:** High  
**Status:** Open  
**Reported by:** Arjun Nair  
**Build:** v0.9.2  
**Environment:** iPhone 14 Pro, iOS 17, Safari Mobile

---

**Steps to reproduce:**
1. Open chatbot on the Samsung Galaxy S22 product page.
2. When the language selection prompt appears, select **Hindi**.
3. Type: "इस फ़ोन की बैटरी कितने mAh की है?" (What is the battery capacity of this phone in mAh?)

**Expected result:**  
Per Technical Requirement 5, the chatbot should respond in the user's selected language. Response should be in Hindi.

**Actual result:**  
The chatbot acknowledges the language selection in Hindi ("आपने हिंदी चुनी है") but then responds to the query entirely in English: "The Samsung Galaxy S22 has a 3700 mAh battery." The language selection setting does not persist to the response generation step.

**Related PRD requirement:** Technical Requirement 5  
**Related test case:** TC-012

**Notes:** Reproducible 100% on iOS Safari. Not yet tested on Android. Language selection appears to update the UI locale string but is not being passed as a parameter to the NLP response API. Data Science and Engineering to investigate the language parameter handoff in the API call chain.
