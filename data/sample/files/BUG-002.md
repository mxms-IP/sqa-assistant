# BUG-002.md

**ID:** BUG-002  
**Title:** Chatbot returns order status information when user asks about delivery for a product not yet purchased  
**Severity:** High  
**Priority:** High  
**Status:** Won't Fix  
**Reported by:** Priya Sharma  
**Build:** v0.9.2  
**Environment:** Safari 17, macOS Sonoma, desktop

---

**Steps to reproduce:**
1. Open the Samsung Galaxy S22 product page.
2. Open the chatbot.
3. Ask: "Where is my order?"

**Expected result:**  
Per the PRD Non-Goals, the chatbot should not handle order status queries. It should decline gracefully and direct the user to customer support.

**Actual result:**  
The chatbot attempted to answer by pulling from a connected order API and returned "I could not find any recent orders for this account." This constitutes handling an out-of-scope query rather than redirecting.

**Related PRD requirement:** PRD Non-Goals (order status explicitly excluded)  
**Related test case:** None — out-of-scope scenario  

**Notes:** Product team reviewed and marked Won't Fix. Rationale: the current response does not expose order data and the redirect message from the API is considered acceptable UX. Team acknowledges this contradicts the Non-Goals but considers the risk low. Revisit in v1.1 scope discussion.
