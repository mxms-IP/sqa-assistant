# BUG-012.md

**ID:** BUG-012  
**Title:** Budget deal suggestion shows price and savings percentage but no product photo  
**Severity:** Low  
**Priority:** Low  
**Status:** Fixed  
**Reported by:** Priya Sharma  
**Build (reported):** v0.9.1  
**Build (fixed):** v0.9.2  
**Environment:** Chrome 124, desktop, macOS Sonoma

---

**Steps to reproduce:**
1. Open chatbot on the Samsung Galaxy S22 product page.
2. Ask: "Is there anything cheaper with similar features?"

**Expected result:**  
Per Technical Requirement 6, budget deal suggestions should include photo, price, and percentage savings for each suggested product.

**Actual result:**  
In build v0.9.1, the chatbot returned the suggested product name, price (₹54,000), and savings (27% off) but the product image area showed a broken image placeholder. Photo URL was returned as null in the API response.

**Related PRD requirement:** Technical Requirement 6  
**Related test case:** TC-014

**Notes:** Fixed in build v0.9.2. Product image CDN integration corrected. TC-014 now passes. Verified by Riya Menon on 2026-09-10.
