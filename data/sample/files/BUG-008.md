# BUG-008.md

**ID:** BUG-008  
**Title:** User reviews summary includes fabricated review text not present in product database  
**Severity:** Medium  
**Priority:** High  
**Status:** Fixed  
**Reported by:** Priya Sharma  
**Build (reported):** v0.9.1  
**Build (fixed):** v0.9.2  
**Environment:** Safari 17, iPad OS 17, tablet

---

**Steps to reproduce:**
1. Open chatbot on the Samsung Galaxy S22 product page.
2. Ask: "What are users saying about the camera quality?"

**Expected result:**  
Per Technical Requirement 3, the chatbot should return a summary of actual user reviews from the product database. Reviews should be grounded in the retrieved data.

**Actual result:**  
In build v0.9.1, the chatbot generated a review summary that included phrases such as "best-in-class zoom capability" and "outperforms the Pixel 7" — neither phrase appears in any review in the mock product database. The chatbot was hallucinating review content.

**Related PRD requirement:** Technical Requirement 3  
**Related test case:** TC-009

**Notes:** Fix applied in v0.9.2 — NLP response generation now strictly grounded to retrieved review excerpts with source IDs attached. Post-fix verification confirmed no fabricated content in three re-runs. TC-009 passes in v0.9.2.
