# BUG-004.md

**ID:** BUG-004  
**Title:** Chatbot misclassifies "Is this phone worth it?" as a discovery query instead of a decision query  
**Severity:** Low  
**Priority:** Low  
**Status:** Open  
**Reported by:** Arjun Nair  
**Build:** v0.9.2  
**Environment:** Chrome 124, desktop, Ubuntu 22.04

---

**Steps to reproduce:**
1. Open chatbot on the Samsung Galaxy S22 product page.
2. Type: "Is this phone worth it?"

**Expected result:**  
Per Technical Requirement 2, the chatbot should understand the user's intent. "Is this phone worth it?" is a decision-making query — the response should address value, key specs, and user sentiment to support a purchase decision.

**Actual result:**  
The chatbot responded by listing three alternative products (discovery behavior), ignoring the current product entirely. The user's intent was clearly evaluative, not exploratory.

**Related PRD requirement:** Technical Requirement 2  
**Related test case:** TC-003 (adjacent — TC-003 passed with the exact scripted query; this is a natural-language variant)

**Notes:** TC-003 passed because it used the exact scripted phrase "Is this phone good for gaming?" — the NLP model correctly handled that phrase. This bug exposes a gap in intent classification for value-judgment phrasing. Data Science team to review training data coverage.
